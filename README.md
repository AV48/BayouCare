BayouCare is a generative AI chatbot created on Hugging Face that uses a Retrieval-Augmented Generation (RAG) system to assist low-income Louisianians in finding affordable healthcare options. The user can input their address, and the chatbot will search through the knowledge base (a list of all the healthcare facilities in Louisiana) to recommend the user affordable and accessible facilities. The knowledge base was retrieved from the HRSA Data Warehouse.
